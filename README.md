#  TrafficOptimizer

**TrafficOptimizer** is a lightweight, smart traffic improvement mod for *Cities: Skylines*. It is designed to keep your city flowing smoothly and reduce congestion without sacrificing game performance.

 **[Download on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3817309797)**

## Features

*   **Smart Lane Balancing:** Gently distributes vehicles across available lanes to prevent single-lane bottlenecks and underused roads.
*   **Congestion Reaction:** Dynamically reacts to heavily loaded roads and intersections, helping to clear traffic jams faster.
*   **Zero Performance Hit:** Designed to be extremely lightweight. No FPS drops, no heavy background calculations. Just pure, efficient optimization.
*   **Plug & Play:** No complex configuration required. Subscribe, enable, and watch your traffic improve immediately.

## ️ Installation

### Via Steam Workshop (Recommended)
1. Go to the [Steam Workshop page](https://steamcommunity.com/sharedfiles/filedetails/?id=3817309797)
2. Click the green **Subscribe** button.
3. Launch *Cities: Skylines*.
4. Go to **Content Manager** -> **Mods** and enable **TrafficOptimizer**.

### Manual Installation
1. Download the latest release `.dll` file from the [Releases](../../releases) section.
2. Place the `.dll` file into your mods folder:
   `Documents/Cities_Skylines/Addons/Mods/`
3. Launch the game and enable the mod in the Content Manager.

##  Compatibility

*   Works perfectly with the vanilla game.
*   Compatible with most other lightweight mods.
*   *Note: If you are using heavy traffic overhauls (like TM:PE), TrafficOptimizer can still work alongside them, but its effects might overlap.*
